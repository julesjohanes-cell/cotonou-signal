Cotonou Signale· Maquettes d'interface

Maquettes par fonctionnalité

10 parcours en 3 formats (smartphone 360, tablette 820, ordinateur 1440), soit 30 maquettes. Clique sur un aperçu pour l'ouvrir en taille réelle. Tout fonctionne hors ligne : aucun serveur, aucune installation.

  • Composants Ant Design 6 avec le thème du design system ; icônes @ant-design/icons, aucun emoji.
  • Logotype « Cotonou Signale » dans l'en-tête ; logo « Cotonou Code la nuit » sur l'accueil.
  • Textes, statuts, catégories et seuils alignés sur le contrat /api/v1 : la route utilisée est indiquée sous chaque parcours.
  • Maquettes statiques : les champs et menus ne réagissent pas. Le détail des choix est dans README.md.

1 Accueil

Aucun appel d'API : page d'entrée.

2 Signaler : choisir la catégorie

GET /api/v1/categories (« autre » part en modération)

3 Signaler : photo prise sur place

champ photo du POST /reports (JPEG, PNG ou WebP, 8 Mo)

4 Signaler : point exact et publication

POST /api/v1/reports (GPS 50 m, point 100 m, description 280 car.)

5 Signaler : confirmation et numéro de suivi

201 { tracking_code, status, duplicate, support_count, message }

6 Refus du serveur (photo hors sujet)

422 { error: { code: PHOTO_MISMATCH, message } }

7 Lien WhatsApp /capture/[token] expiré

GET /api/v1/capture-sessions/{token} → 410 TOKEN_EXPIRED

8 Carte publique

GET /api/v1/reports (GeoJSON, aucune donnée perso)

9 Suivi d'un signalement

GET /api/v1/reports/{tracking_code} (history[] avec la note, jamais le nom de l'agent)

10 Espace mairie (bonus, sinon Django admin)

GET /agent/reports · PATCH { status, note } · POST after-photo
